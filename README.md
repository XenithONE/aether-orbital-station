# AETHER — Orbital Station

地球軌道から別の銀河へ。細部まで作り込んだ研究ステーションを歩き、窓の向こうの宇宙を探索するブラウザー用 3D シミュレーター。

**[ステーションを開く](https://xenithone.github.io/aether-orbital-station/)** · **[WebGPU ビューアを開く](https://xenithone.github.io/aether-orbital-station/viewer.html)** · **[外装 GLB を WebGPU で見る](https://xenithone.github.io/aether-orbital-station/viewer.html?station=1)**

本体も独立ビューアも **Three.js 0.185.1 の WebGPURenderer** を使用します。WebGPU が使えない環境では WebGL 2 に自動で切り替わります。Blender MCP で制作した二重リングの外装、実際の表面画像を使った金属材質、HDRI による反射、Rapier による歩行と衝突判定を備えています。

## 体験できること

- **3 つの宇宙へワープ**：地球軌道、紫と翡翠のオーロラ星雲、光の降着環に包まれたガルガンチュア。充電 5 秒 → 跳躍 7 秒 → 到着 4 秒。光の収束、立体トンネル、通過するリング、出口から広がる景色を楽しめます。
- **未来的な操縦卓**：分割した陶器シャーシ、薄い反射防止ガラス、湾曲した計器、埋め込み投影レンズ。航路・充電アーク・ホログラムが航行状態と連動し、各区画の操作盤にも同じデザインを採用しています。
- **9 件の観測記録**：各宙域で研究室のスキャナーを操作して、3 件ずつ航海記を集めます。集めた記録は保存されます。
- **4 区画を歩いて探索**：展望室、寝台・食堂のある居住区、水耕栽培の研究室、機関室。壁面パネル、留め具、配管、ケーブル、折り重ねた布、小物まで配置しています。
- **目の前で変化する設備**：6 惑星のホログラム天体儀、植物が成長するバイオスフィア、観測ドローン MILO の離陸・巡回・ドックへの帰還。
- **ステーションの運転**：ハッチ、窓シャッター、照明、太陽電池、リアクター、人工重力、航行ビーコンを操作。重力を切ると上下に浮遊でき、研究室の試料も浮き上がります。
- **景色を楽しむ機能**：外観カメラ、区画マップ、環境音とワープ音、画面 UI を含めない PNG 撮影、描画品質・視点感度の変更。

## 最初の 3 ステップ

1. **展望室で操作を覚える。** 「ステーションに入る」を押し、WASD で歩きます。画面をドラッグして見回し、設備に近づいて表示が出たら E。中央の天体儀や MILO のドックも試してみてください。
2. **新しい宇宙へ出発する。** 中央の航路テーブルで E、または画面上の現在地ボタンから航路を開きます。「オーロラ星雲」を選んでワープを起動。充電中は中止でき、跳躍開始後は自動で到着します。地球への帰還も同じ操作です。
3. **観測と機関室の実験を楽しむ。** M で研究室へ移動し、スキャナーで記録を集めます。1 回の観測は約 3 秒です。機関室では人工重力を切り、Space / Q で浮遊。展望室へ戻ったら P で好きな景色を撮影できます。

ワープには **主電源 ON・電力 72% 以上** が必要です。停止している場合は機関室のリアクターを起動します。充電中の給電中断では航路を中止します。航路画面には、光とカメラの動きを抑える設定もあります。

航路画面の **HELIOS** は現在地から目的地までの航路図と、主電源の準備状態を表示します。航行中は船内照明が落ち、青い光の映り込みと視野の変化が加速・減速に追従します。音も楽しむ場合は、出発前に画面右上の **♪** をオンにしてください。

## 起動

Node.js 22.12 以降で、次のコマンドを実行してください。

```powershell
npm install
npm run dev
```

画面の「ステーションに入る」から探索を始めます。

| 操作 | キー |
|---|---|
| 歩く | WASD |
| 速く移動 | Shift |
| 見回す | 左ドラッグ / 矢印キー |
| マウス固定 | F、解除は Esc |
| 近くの設備・ハッチ | E |
| マップ | M |
| 内部・外観 | V |
| 写真 | P |
| 無重力時の上下移動 | Space / Q |
| 航路・観測ログ | 現在地ボタン / 展望室の航路テーブルで E |

タッチ端末では画面の移動ボタンとドラッグ操作を使います。

## WebGPU 単一 HTML ビューア

`public/viewer.html` はビルド不要の独立したビューアです。

Three.js 0.185.1 の WebGPURenderer、自動 WebGL 2 フォールバック、HDRI、3 灯照明、PCF ソフトシャドウ、GTAO、Bloom、ACES、GLB ドロップに対応します。Blender の材質設定・書き出し手順と完全コードは **[WEBGPU_GUIDE.md](WEBGPU_GUIDE.md)** にあります。

GLB は本体とビューアで共通利用できます。独立ビューアは Three.js と初期 HDRI を CDN から取得するため、ネット接続が必要です。本体は HDRI とモデルを同梱して公開しています。

## 描画品質

本体にも Poly Haven の **Studio Small 09** を環境光として使用し、材質への映り込みを作ります。キー・フィル・リムの 3 灯、ACES の明るさ変換、色補正、PCF ソフトシャドウを組み合わせています。影のマップは PC で 4096、タッチ端末で 2048 です。

| 設定 | 表現 |
|---|---|
| 高品質 | 接地感を補う GTAO、発光をにじませる Bloom、影 |
| 標準 | Bloom、影、描画解像度を調整 |
| 軽量 | GTAO・Bloom・影を省き、描画解像度を調整 |

タッチ端末では標準設定と軽い地球テクスチャを選びます。動作が重い場合は「設定」から描画品質を下げてください。リアルタイム描画のため、Blender の Cycles による静止画レンダリングと同じ計算ではありません。遠方の銀河や天体、ワープ、航海記は探索用に創作した世界で、天文学的な数値計算や宇宙飛行訓練を目的としたものではありません。

## アセット

- `blender/aether-station.blend`：Blender 元データ。
- `blender/build_station.py`：MCP または Blender の Python で実行する制作スクリプト。Blender の Text Editor でこのファイルを開いて実行すると再制作できます。MCP から exec する場合は `__file__` にこの Python ファイルの絶対パスを渡します。
- `public/assets/station.glb`：PBR 画像を内蔵した Meshopt 圧縮モデル。
- `blender/survey-drone.blend` / `blender/build_survey_drone.py`：MILO の Blender 元データと制作スクリプト。今回の追加モデルは Blender MCP が接続できなかったため、インストール済み Blender のバックグラウンド実行で制作しました。
- `public/assets/survey-drone.glb`：MILO の表示用モデル。
- `public/assets/studio_small_09_1k.hdr`：本体に同梱した 1K HDRI。
- `src/interior.ts`：内部・コリジョン・設備の定義。
- `src/interior-details.ts`：内装の細部、植物、天体儀の演出。
- `src/command-console.ts`：中央操縦卓・周辺計器の形状、反射防止材質、動的な航路表示。
- `src/cosmos.ts`：地球・星雲・降着環・ワープ空間の描画。
- `src/warp-effects.ts`：船外に配置した立体トンネル、開口する出口、収束粒子、航行リング。
- `src/rendering.ts`：本体の WebGPU / WebGL 2 共通の描画処理。
- `src/warp.ts` / `src/warp-ui.ts`：航行・観測の状態と航路画面。
- `src/drone.ts`：MILO の飛行と充電ドック。
- `src/simulation.ts`：設備の状態と環境音。
- `src/main.ts`：操作・物理・画面管理。

外装と内部は、参考画像から着想した体験用の別々の表示モデルです。外部カメラと内部探索は表示モードで切り替えます。

出典とライセンスは **[ASSET_CREDITS.md](ASSET_CREDITS.md)** を参照してください。

## ビルドと公開

```powershell
npm run build
npm run preview
```

`dist` に GitHub Pages 用の静的ファイルを出力します。リポジトリの Settings → Pages → Source を **GitHub Actions** に設定し、`main` に push すると `.github/workflows/deploy.yml` がビルド・公開します。リポジトリ配下のパスでも動く相対 URL 構成です。

## 検証

Playwright CLI によるスクリーンショット確認、実際の移動・設備操作、壁・家具・ハッチとの衝突、4 区画への移動、PC / モバイル表示を検証しています。詳しい結果は **[VALIDATION.md](VALIDATION.md)** を参照してください。

探索済み区画・操作履歴と、9 件の観測記録を localStorage に保存します。再読み込みすると地球軌道に戻り、設備は初期状態に戻ります。
